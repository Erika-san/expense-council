# 出費会議 PRD

欲しいものを登録して2択に答えるだけで、予算内の買い物が決まるようにするための要求をまとめます。

## 背景と課題

欲しいものが多く予算が限られるとき、何を先に買うかが決まらず、月初に時間がかかります。

- 全部を一度に見比べても、優先順位がつかない。
- 予算との兼ね合いが後回しになり、買った後で足りなくなる。
- 1つずつ「欲しい度」を点数で付けるのは難しい。2つのうちどちらかなら選べる。

方針は、選ぶ作業だけを人が行い、順位づけと予算への当てはめはアプリが行うことです。

## ユーザーとストーリー

想定ユーザーは、毎月使えるお金が決まっている個人です（通貨はルピア）。

| ID | したいこと | 目的 |
| --- | --- | --- |
| US-1 | 予算を決めたい | 使える上限を超えないため |
| US-2 | 欲しいものを名前・値段・アピールポイントで登録したい | 比べるときに魅力を思い出せるように |
| US-3 | 2つを見比べて欲しい方を選びたい | 点数を付けずに優先順位を決めるため |
| US-4 | 間違えたら1つ前に戻したい | 誤答で結果が歪まないように |
| US-5 | 結果から、買ったものを記録したい | 残り予算を最新にするため |
| US-6 | 今月は見送るものを外したい | 比較を軽くし、後で戻せるように |
| US-7 | 不要になったものを消したい | 一覧をきれいに保つため |
| US-8 | 後から欲しいものを足したい | 全部やり直さず、少ない質問で順位に入れるため |

## 機能要件

| ID | 要件 | 優先度 | 状況 |
| --- | --- | --- | --- |
| FR-1 | 予算（Rp）を設定できる。整数で、残り予算として扱う | 必須 | 実装済み |
| FR-2 | 名前（30文字まで）・値段（1以上）・アピールポイント（60文字まで、任意）でアイテムを登録できる。active は16件まで | 必須 | 実装済み |
| FR-3 | 新しいアイテムを順位表に二分探索で入れる2択の質問を出す | 必須 | 実装済み |
| FR-4 | 「どちらでもいい」と「ひとつ戻る」が使える | 必須 | 実装済み |
| FR-5 | 順位を点数に変え、予算内で合計点が最大の買い物を全探索で出す | 必須 | 実装済み |
| FR-6 | 「買った」で予算から値段を引き、購入済みにする | 必須 | 実装済み |
| FR-7 | 購入を取り消すと、予算が戻り候補に戻る | 任意 | 実装済み |

| FR-10 | 後から追加したアイテムは、既存の順位に挿入する質問だけで入れる | 必須 | 実装済み |
| FR-11 | 入力内容をブラウザへ自動保存し、再訪時に復元する | 必須 | 実装済み |
| FR-12 | 複数端末で同じデータを使える | 将来 | 未着手 |

## 質問方式の仕様

新しいアイテムが、できあがった順位表の「どこに入るか」を二分探索で決めます。

1. 最初のアイテムは、質問なしで1位に置く。
2. 次のアイテムを、順位表の真ん中のアイテムと比べる。
3. 新しい方を選べば上半分、選ばなければ下半分に候補を絞る。
4. 候補が1か所に絞れたら、そこに入れて次のアイテムへ進む。
5. 全アイテムが入れば、質問は終わり。

決まり:

- 左右の配置は、質問ごとに入れ替える。位置の偏りを防ぐため。
- 「どちらでもいい」は、新しいアイテムを下に置く扱い。
- 質問の順番は、アイテムをランダムに並べ替えた順。
- 質問の相手になるのは、status が active のアイテムだけ。
- 完了後に追加したアイテムも同じ方式で入れる。active が15件なら、追加の質問は最大4問。

質問数は次のとおりです。

| 件数 | 全ペアを比べる方式 | この方式（最短〜最大） |
| --- | --- | --- |
| 8件 | 28問 | 13〜17問 |
| 16件 | 120問 | 38〜49問 |
| 30件（参考。上限外） | 435問 | 94〜119問 |

## アイテムの状態と操作

| 状態 | 比較に出る | 順位 | できる操作 |
| --- | --- | --- | --- |
| 候補（active） | 出る | あり | 買った / やめる / 削除 |
| 購入済み（bought） | 出ない | 保つ | 購入を取り消す / 削除 |
| やめた（inactive） | 出ない | 保つ | 復活 / 削除 |
| 削除 | なし | 消える | なし（元に戻せない） |

- 「買った」は、予算から値段を引く。購入の取り消しは、予算に値段を戻す。
- 予算を超える値段のアイテムは active のままで、比較と選定の対象から外れる。予算が増えれば、また対象になる。

## 非機能要件

- 件数: active のアイテムは16件まで。
- 質問数: 16件で最大49問。
- 計算時間: 結果の計算は1秒未満。16件の全探索は約0.04秒だった。
- 保存: localStorage に、変更のたびに保存する。
- 表示: スマホ幅（約400px）から使え、ライトとダークに対応する。
- 金額: Rp の整数のみ。表示は id-ID 形式（Rp 1.800.000）。
- 操作: 質問には、タップのほか ← → キーでも答えられる。

## スコープ外と未決事項

スコープ外は、ログイン、共有、複数端末の同期、ショップ連携、価格の自動取得、為替換算、月ごとの履歴です。

| 未決事項 | 案 |
| --- | --- |
| 買う・買わないの境目が決まった時点で、質問を打ち切るか | 打ち切れば質問は減るが、下位の順位が不正確になる。まず全順位で実装し、後で検討する |
| 購入済み・やめたアイテムの順位を、どう扱うか | 順位を保つ。復活したときは元の位置に戻る |
| 月が替わったときのリセット | 当面は、手動の「すべて消して最初から」のみ |
| 「どちらでもいい」が多いときの扱い | 新しい方を下に置く規則のまま |
