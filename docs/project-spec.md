# 出費会議 プロジェクト仕様

Oct 21, 2026 · @Erika

出費会議は、欲しいものを登録して2択に答えるだけで、予算内の買い物を決めるブラウザアプリです。このタブにプロジェクトの目的・範囲・計画をまとめます。

関連: PRD · 完了の定義（DoD） · ER図・データ設計

## 目的とゴール

月初に「来月は何を買うか」で悩む時間をなくします。

- ゴール: 欲しいものを最大16件登録し、2択に答えるだけで、予算内で一番合理的な買い物を出せる。
- 成功の目安: 16件の登録から結果が出るまでの質問が最大49問に収まる。全ペアを比べる方式の120問の約4割です。結果の計算は1秒未満で終わる。
- 使い続けてもらう条件: 「買った」「やめる」を押すだけで、残り予算と買うものが最新になる。

## 対象範囲

| 区分 | 内容 |
| --- | --- |
| 作る | 予算とアイテム（名前・値段・アピールポイント）の登録 |
| 作る | 1件ずつランキングに入れていく2択の質問 |
| 作る | 予算内で一番合理的な買い物の計算 |
| 作る | 買った・やめる・削除・復活・購入の取り消し |
| 作る | ブラウザへの自動保存 |
| 作らない | ログイン、複数人での共有、複数端末の同期 |
| 作らない | ショップ連携、価格の自動取得、為替換算 |
| 作らない | 月ごとの履歴（将来の拡張） |

## 前提と制約

| 項目 | 内容 |
| --- | --- |
| 通貨 | ルピア（Rp）。整数のみ。表示は「Rp 1.800.000」の形 |
| 件数 | 登録中（active）のアイテムは16件まで |
| 保存 | ブラウザの localStorage のみ。端末間では共有されず、サイトデータを消すと消える |
| 動作環境 | 最新のブラウザ。スマホ幅（約400px）から使え、ライトとダークに対応 |
| 通信 | 外部サーバーとのやり取りはない |
| 言語 | 日本語 |

## 技術構成

サーバーを持たない単一のHTMLページです。

| 層 | 内容 |
| --- | --- |
| 画面 | 登録・比較・結果の3画面を1ページ内で切り替える |
| 状態 | 予算、アイテム、順位、進行状態、回答履歴を1つのオブジェクトで持つ |
| 質問ロジック | 新しいアイテムを順位表に二分探索で入れる。1問ごとに候補の範囲が半分になる |
| 選定ロジック | 順位を点数に変え、予算内で合計点が最大になる組み合わせを全探索で選ぶ。16件なら65,536通りで、約0.04秒 |
| 保存 | 変更のたびに localStorage へ保存し、起動時に読み込む |

件数の上限を増やすときは、選定ロジックだけを動的計画法に差し替えます。

## マイルストーン

| 段階 | 内容 | 状況 |
| --- | --- | --- |
| M1 | 登録・予算・結果の基本画面（全ペアを比べる方式） | 実装済み |
| M2 | 買った・やめる・削除・復活・購入の取り消し | 実装済み |
| M3 | 質問方式を「1件ずつ入れる」に置き換え、点数を順位ベースに変更 | 実装済み |
| M4 | 受け入れテスト（完了の定義の全項目） | 実装済み（自動テスト33件合格。完了の定義の全項目にチェック済み） |
| M5 | 公開 | 未着手（GitHub への公開は確認待ち） |

## リスクと対応

| リスク | 対応 |
| --- | --- |
| 1回の誤答が順位に大きく響く | 「ひとつ戻る」をいつでも使えるようにする。結果画面から比較をやり直せる |
| 買う・買わないの境目だけ分かれば足りるのに、全順位を聞いてしまう | 境目が決まった時点で質問を打ち切る工夫は、PRDの未決事項として後で決める |
| localStorage が消えてデータを失う | 当面は画面に注意書きを出す。将来はサーバー保存を検討する |
| 件数を増やしたくなる | 選定ロジックを動的計画法に差し替える。質問は同じ方式のまま対応できる（30件でも最大119問） |
| 「どちらでもいい」が多いと順位が偏る | 新しい方を下に置く規則で、順位は必ず決まる。この規則を画面で説明する |
